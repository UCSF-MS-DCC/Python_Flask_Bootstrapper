For quick setup of a barebones Python Flask application.
To run, cd into the directory containing prototype.py and run `python prototype.py`

Additional flags can be applied:
--stubs : Takes whole numbers from 1 to 5 - creates this number of stub controller actions and index.html files. URLs created are: /first/index.html, /second/index.html, etc.
--build-dir : Takes a file path as a value and sets up the Flask application in that location. Default behavior is to set up the Flask application in the current directory
